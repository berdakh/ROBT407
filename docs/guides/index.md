# Reference guides

The notebooks are hands-on. These are the reference material behind them, and
each stands alone.

- [**Setup**]({{ '/guides/setup.html' | relative_url }}) — local install, Google
  Colab, and running fully offline.
- [**Bias reference**]({{ '/guides/biases.html' | relative_url }}) — one page:
  every bias, how it gets in, how to detect it, how to prevent it.
- [**Tool ecosystem**]({{ '/guides/tools.html' | relative_url }}) — fourteen
  tools, each with the problem it solves *and when not to use it*.
- [**Library reference**]({{ '/guides/library.html' | relative_url }}) — the
  `algotrade` package, module by module.
